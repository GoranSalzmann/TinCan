# M5 demo checklist (hardening and operations)

Rows marked **VPS** need the real server (mkarl.io); **people** need a second person. Everything else you can do on a laptop with `pnpm dev`, a local LiveKit (`sh tools/media-test/docker.sh` shows how) or the automated commands listed. Tick, or write what you saw. Facts and cuts: [18 §M](../18-open-questions-and-risks.md); admin steps: [admin guide](../guides/admin-guide.md).

## A. Automated (nothing to see, just run)

- [ ] `pnpm check` is green (typecheck, lint, headers, all tests, build, licences, secrets).
- [ ] `sh tools/media-test/docker.sh`: all steps pass, including the three E2EE steps (about 8 minutes).
- [ ] `node tools/upgrade-rehearsal/run.mjs --old <checkout of an earlier release>`: 12/12.
- [ ] `pnpm load` (about 2 minutes) prints the numbers in 18 §M; `sh tools/load/soak.sh` for a longer soak.

## B. Moderation (people for the voice rows)

Set up: the owner, one Moderator, one Admin, two plain members (Ann, Bo).

- [ ] Member card → **Time out** Ann for 1 minute with a reason: Ann cannot send (error), the card shows "Timed out until …", it ends by itself and Ann can send again.
- [ ] Ann and Bo in a voice channel (**people**): **Server mute** Ann: the microphone button turns off by itself, others see her marked red; she leaves and rejoins and is still muted; **Remove server mute** restores it without rejoining.
- [ ] **Server deafen** Bo: Bo hears nothing; lifting it brings sound back.
- [ ] **Move** Ann to another voice channel: she lands in it without clicking; **Disconnect** sends her out with the notice "A moderator disconnected you".
- [ ] **Kick** Ann: she is signed out wherever she is (a second browser too); she can sign in again.
- [ ] **Ban** Bo with "delete the last 7 days": his messages vanish for everyone; his login says banned and shows the reason; **Settings › Moderation › Banned people → Lift ban** lets him in.
- [ ] A Moderator cannot ban (no button), cannot act on another Moderator or an Admin (the error names the rank), and nobody can act on the owner or themself.
- [ ] **Settings › Moderation** lists every action above with who, whom, when and the reason; the filter and "Load more" work.
- [ ] Restart the server during a timeout: it is still in force afterwards.

## C. Voice encryption

- [ ] Settings › Server › **Encrypt voice calls by default** is on for a new install. A voice channel shows a lock in the sidebar; the call shows "End-to-end encrypted" with the honest tooltip.
- [ ] Two browsers in an encrypted call hear each other; camera and screen share work (watch one) at a preset and at a custom quality (people).
- [ ] A third person joins late: hears and sees everyone.
- [ ] Kick or move someone out while two others talk: the two keep hearing each other without more than a short blip. Settings › Server shows nothing wrong; `GET /api/v1/metrics` has `tincan_voice_e2ee_rotations_total` increased (**VPS** or local).
- [ ] Change the channel to **Never encrypt** during a call: everyone is restarted into an unencrypted call and the lock is gone. Change to **Always encrypt** with server default off: the lock returns.
- [ ] Restart the app container during an encrypted call: the call goes on and a new joiner can still hear (same key from the room, no rekey).
- [ ] `tincan e2ee rotate-secret` during a call: within 30 seconds the call rekeys and nobody drops.
- [ ] **Firefox** (people): joins an encrypted call, or is refused with a clear message. Safari/phone: same. Note what you see.
- [ ] A browser that cannot do it (try an old one, or disable it with a flag) is refused with "this call is end-to-end encrypted …".

## D. Backup and restore

- [ ] `tincan backup --out ./backups` while the app runs: an archive appears; `tar -tzf` lists `manifest.json`, `db/app.db`, `files/…`, `config/…`; no `.env`.
- [ ] `tincan restore <archive> --into ../scratch`, copy `.env` in, `docker compose up -d` on another port: your members, channels, messages and a file you uploaded are all there. (**VPS**: do this on mkarl.io into a scratch directory.)
- [ ] A byte flipped in the archive makes restore refuse with "does not match its checksum".
- [ ] `--keep 3` removes older archives; `--include-secrets` adds `.env`.
- [ ] Run a real upgrade on a copy and read `data/backups/pre-migrate-*.db`.

## E. Metrics and dashboards

- [ ] `curl -i http://127.0.0.1:3000/api/v1/metrics` on the host returns Prometheus text; from outside (through Caddy) it is 404; with the wrong token 403.
- [ ] `docker compose --profile dashboards up -d`, tunnel to port 3001, open the "Tin Can" dashboard: panels fill within a minute. Join a call and watch "People in voice" move (**VPS**).
- [ ] Break the LiveKit webhook URL on a scratch install: "Voice reconciler repairs" climbs and the alert appears in Prometheus.

## F. Security checks (VPS)

- [ ] `tincan doctor --url https://mkarl.io` has no failures.
- [ ] From another machine, `curl -I https://mkarl.io` shows HSTS, CSP, `Cross-Origin-Opener-Policy`, nosniff; `/api/v1/internal/livekit/webhook` and `/api/v1/metrics` are 404.
- [ ] Only the expected ports answer (`nmap -p 3000,7880,9090,3001 mkarl.io` shows closed).
- [ ] Sign in with a wrong password six times: you are slowed, the message never says which part was wrong.
- [ ] Upload an HTML file and open its link: it downloads, nothing runs.
- [ ] Post `<img src=x onerror=alert(1)>` and a `javascript:` link: they show as text.

## G. Load and memory

- [ ] Raise the file limit to 200 MB on a scratch install, upload three large files at once from three accounts: the third gets "busy, try again" instead of the server running out of memory; `tincan_uploads_busy_total` goes up.
- [ ] Decide: do you want streaming uploads (18 §M)?

## H. Update the live server (VPS, your call)

The admin guide §6 lists the by-hand edits for an instance made before M5: the metrics token in `.env`, two Caddyfile lines, optionally `monitoring/`. Nothing here is needed for moderation, E2EE or backups, which come with the new image.

## I. Not tested by me

Firefox, Safari, phones, AV1 under E2EE, the real screen picker, the VPS, TURN, more than three people, a soak longer than 6 minutes, and any screen reader.

## J. Accessibility and performance (people)

- [ ] Keyboard only: reach the member card, the moderation buttons, the Moderation pane and the lock tooltip (Tab, Enter, Esc); dialogs trap focus and return it.
- [ ] A screen reader reads "Server muted" for a muted person and "End-to-end encrypted" in the call header.
- [ ] Zoom to 200 % and 320 px wide: the Moderation pane and card do not scroll sideways.
- [ ] Open the app on a slow phone connection: time to the login screen; main script is 225 kB gzipped.
