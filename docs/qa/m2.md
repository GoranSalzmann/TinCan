# M2 demo checklist

What M2 delivers: a text-only Tin Can a friends group can use daily. Built 2026-10-29. Cuts and deferrals:
[18 §I](../18-open-questions-and-risks.md#i-m2-build-notes-2026-10-29).
What has been run: the server side of every section by automated tests (rows in A), and a manual pass in the
browser against a local server covering login, the channel list, sending, Markdown, `@` autocomplete, live
delivery, unread and mention badges, the tab title, and the Roles pane. **The other web rows (uploads, drag and drop,
avatars, notifications, retry after going offline, search dialog, invite page, member list groups, the admin panes
other than Roles, a phone-width layout) were built and type-checked but not yet clicked through; please walk them.**
Rows marked **(you)** also need a second device or machine.

## A. Local checks (no Docker)

```bash
pnpm install
pnpm check
```

- [ ] `pnpm check` is green: typecheck, lint, SPDX headers, 830+ tests, build, licence scan, secret scan.
- [ ] `pnpm test:matrix`: the module boot matrix (now over the real `roles`, `channels`, `text-chat`, `read-state`, `invites`, `uploads` and `search`) and the **authorisation matrix** (`apps/server/src/authz.matrix.test.ts`, 420 cases: every permission-gated endpoint × owner, admin, moderator, member, restricted, outsider, anonymous × open, private and read-only channels, plus leak and privilege-escalation tests).
- [ ] Contract suites: DB (now including `readOnly()` on the worker connection), storage, pubsub, auth.

## B. Run it and look around

Quickest way, without compose:

```bash
pnpm build
node apps/server/dist/cli.js init --dir ../tincan-m2 --domain localhost --http-port 8081 --yes
cd ../tincan-m2 && docker compose up -d --build
```

or for development: `pnpm dev` (server on :3000) and `pnpm --filter @tincan/web dev` (web on :5173; use `localhost`, which is the configured origin).

- [ ] After the setup wizard the sidebar has **Text channels › #general** and **Voice channels › Lounge** (Lounge is dimmed: voice arrives in M3). The Admin and Moderator roles exist (Settings › Roles).
- [ ] `pnpm tincan perms explain --user <you> --channel general` prints each step of the permission computation.

## C. Messaging (W-03, W-04)

- [ ] Send a message: it appears at once (dimmed "Sending…"), then confirms. The list stays at the bottom while you send and while others write.
- [ ] Markdown: `**bold**`, `*italic*`, `~~strike~~`, `` `code` ``, a fenced block, `> quote`, a list, `||spoiler||` (click to reveal). `<script>` shows as text.
- [ ] Links: `https://example.com` opens in a new tab. `[paypal.com](https://evil.example)` asks "Open this link?" first.
- [ ] Type `@` and pick a member (arrow keys, Enter): the message shows a highlighted chip; that member gets a mention badge. `#` offers channels. `@everyone` only works for roles with *Mention @everyone*.
- [ ] Reply (toolbar): the reply shows a reference line; clicking it jumps to the original. Edit (↑ in an empty box, or the toolbar): "(edited)" appears. Delete asks first.
- [ ] Scroll up: older messages load without jumping. After scrolling up, "Jump to latest" appears.
- [ ] Open the same channel in a second tab: messages, edits, deletes, pins and the "… is typing" line arrive live.
- [ ] Break the network briefly (dev tools › offline) and send: the message shows "Not sent" with Retry and Delete. Retrying never creates a duplicate.
- [ ] Pin a message (needs *Manage messages*); the pin icon in the header lists pinned messages and jumps to them.
- [ ] Draft: type, switch channel, switch back: the text is still there.

## D. Unread, mentions, notifications

- [ ] A channel with new messages is bold with a dot; a mention shows a red count; the browser tab title shows `(n)`.
- [ ] Reading the channel at the bottom clears it (also on your other device).
- [ ] Channel menu (the **…** next to a channel): Mark as read, Mute (15 min, 1 h, 8 h, forever), Notifications (default, all, mentions, none).
- [ ] Instance menu › **Turn on notifications**; with the tab in the background a message from someone else raises a notification that opens the channel. Muted channels notify for mentions only.

## E. Uploads and storage (W-23)

- [ ] Attach with the paperclip, paste an image, or drag a file on the composer: progress bar, then the message shows the image (size reserved, no layout shift) or a file card.
- [ ] A file over the limit is refused with the limit named. An HTML or SVG file is only ever offered as a download.
- [ ] Settings › Storage shows used/quota and your uploads, largest first. Deleting one turns it into "File removed" in the message for everyone and frees the quota at once.
- [ ] Settings › My account › change the avatar: it shows in messages and the member list.

## F. Roles, channels, permissions (W-40, W-41, W-42)

- [ ] Settings › Roles: create a role, pick a colour, toggle permissions, "show separately" puts its members in their own group in the member list. You cannot switch on a permission you do not hold.
- [ ] Settings › Channels: create, rename, archive (via the API), delete a channel; create a category. Move up/down in the channel menu.
- [ ] Channel permissions: give `@everyone` **Deny › View channel** on a channel. Another member's open tab loses the channel at once; give it back and it reappears. Member overwrites beat role overwrites.
- [ ] Settings › Members › pick a member: assign roles; the role list is limited to roles below yours. "What can this member do?" explains each step for a channel.

## G. Invites and joining (W-32, W-33, W-43)

- [ ] Settings › Invites: create a link (expiry, uses, optional role). It is copied. Open it in a private window: the invite page names the server and member count; Join creates the account with the role.
- [ ] A used-up, expired or revoked link shows the same "This invite doesn't work" page.
- [ ] Settings › Members › **Create a password reset code**: send it; on the login screen "Use it" sets a new password and signs the account out everywhere.
- [ ] `pnpm tincan user reset-password --username <name>` (and `--owner`) prints a code.

## H. Search (06 §3.9)

- [ ] Ctrl+K (or the magnifier): type a word, results appear newest first; toggle "Only this channel" and "Best match". Clicking a result opens the channel at that message.
- [ ] Results never include channels you cannot read. A message you just sent can take a moment to appear.
- [ ] `pnpm tincan search reindex` rebuilds the index while the server runs and prints a summary.

## I. Not covered by M2 (see 18 §I)

Voice, reactions, link previews, moderation (kick/ban/timeout), audit log, OpenAPI output, an end-to-end browser test, a run on a real VPS with a domain **(you)**, and testing on other browsers and a phone **(you)**.
